# Statistics Project

## Customer Behavior Analysis

This project analyzes customer behavior using statistical and mathematical tools in Python.

### Dataset

The dataset contains the following columns:

- CustomerID
- Gender
- Region
- PurchaseAmount
- ProductCategory
- Churn
- CampaignGroup

### Statistical Analysis

The project covers:

1. Mean, median and mode
2. Outlier detection using IQR
3. Skewness and kurtosis
4. Male vs female spending using t-test
5. Product category vs churn using Chi-square test
6. Regional comparison using ANOVA
7. Campaign A vs B comparison
8. Normality test
9. Central Limit Theorem
10. 95% confidence interval
